수리남케어 24차 사진 교체 수정본 (24-photo.zip)

이 파일은 기존 24차(24.zip)를 아직 적용하지 않은 사용자를 위한 통합 대체본입니다.
24차 기존 HTML 30개 + 각 페이지 별도 사진 2장(총 60장) + 전체 사이트맵/한글 지역목록/목록이 포함됩니다.

[파일 구성]
- *-drain.html : 24차 신규 지역 HTML 30개
- 24-01a.webp ... 24-30b.webp : 실제 제공한 사진을 기반으로 웹 최적화한 총 60개 이미지
- sitemap.xml : 24차 포함 전체 1,133개 URL (원본 24.zip 그대로 유지)
- region-pages.html : 24차 포함 한글 지역목록 (원본 24.zip 그대로 유지)
- urls.txt : 24차 30개 수집요청 URL (원본 그대로 유지)
- keys.csv : 24차 30개 지역 키워드 (원본 그대로 유지)
- PHOTO-MAP.txt : 지역 HTML별 사진 연결 안내
- README.txt : 이 문서

[적용]
1. 기존 24.zip 대신 이 24-photo.zip을 압축 해제합니다.
2. 기존 surinamcare 사이트 최상위 폴더(기존 HTML들이 있는 폴더)에 ZIP 안의 파일 전체를 복사합니다.
3. sitemap.xml / region-pages.html 두 파일은 덮어씁니다.
4. 24-**.webp 파일 60개도 반드시 함께 업로드해야 이미지가 보입니다.
5. 기존 지역 HTML은 삭제하면 안 됩니다.
6. GitHub Desktop에서 Commit -> Push origin, 배포 후 새 페이지에서 이미지/전화 연결을 점검합니다.
7. 네이버 수집요청용 URL은 urls.txt에 있습니다.

[사진 주의]
사용자가 제공한 사진 113장 중 60장을 선정했습니다. 30개 페이지에 사진 2개씩 겹치지 않게 배치했습니다.
각 페이지에 실제 촬영 지역을 확인할 수 없으므로 사진은 작업/장비 설명용 참고 사진으로 표기했습니다.
기존 24차의 사이트맵 URL, 제목, canonical, 본문 내용은 유지합니다.
